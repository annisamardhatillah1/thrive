# thrive
THRIVE adalah aplikasi thrift fashion yang menyediakan berbagai pilihan pakaian secondhand berkualitas untuk perempuan usia 18–30 tahun. Pengguna dapat menemukan pakaian unik dengan harga terjangkau, melihat kondisi dan detail produk, menyimpan produk favorit, hingga melakukan pembelian langsung melalui aplikasi.
